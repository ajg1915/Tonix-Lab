# VDO.Ninja (self-hosted copy)

This folder is an unmodified copy of the open source VDO.Ninja web app,
https://github.com/steveseguin/vdo.ninja (commit 7d85ea9), by Steve Seguin and contributors.
It is licensed under the GNU AGPL v3 (see `LICENSE` and `AGPLv3.md` here).

Tonix Lab embeds it so streams run from this site's own address. Some large optional
add-ons (virtual-background models, 3D scenes, example pages) were left out to keep
the repository small, so those features are not available in this copy.
Full source: the link above.
